# מדריך קצר: לעבוד טוב עם Claude בלי לגמור את המכסה

## איזה כלי לאיזו עבודה
| העבודה | איפה |
|---|---|
| שאלה, רעיון, טיוטת מייל, מסמך שמדביקים לקריאה | צ'אט |
| עבודה על קבצים במחשב (תיקייה, אקסל, וורד, מצגת), סקריפטים, כלים, קוד | לשונית Code |
| מסמכים קבועים שחוזרים אליהם (נהלים, תבניות) | פרויקט (Project) עם המסמכים האלה בלבד |

## שלושה הרגלים
1. **משימה חדשה ← סיכום ואז צ'אט חדש.** בלשונית Code: הקלידו `/handoff` ופתחו צ'אט חדש. בצ'אט: בקשו
   "סכם את מה שעשינו לצ'אט חדש" והדביקו את הסיכום בצ'אט חדש. שאלה על מה שנעשה זה עתה היא לא משימה חדשה.
2. **אותה משימה ← ממשיכים.** בלשונית Code הקיט אומר לבד מתי הצ'אט ארוך מדי. בצ'אט: כשיש בו קבצים, כשהוא
   ארוך מאוד, או כשהשימוש בהגדרות ← Usage עולה מהר, עברו לצ'אט חדש עם סיכום.
3. **לפני הפסקה של שעה ומעלה ← סיכום.** חוזרים לצ'אט חדש שמתחיל מהסיכום.

## עוד דרכים לחסוך במכסה
- **מודל:** Sonnet לעבודה שגרתית, Opus כשהעבודה דורשת שיקול דעת. בוחרים בתחילת הצ'אט, לא באמצע.
  Fable צורך הרבה יותר: רק כשיש סיבה.
- **מאמץ (effort), בלשונית Code:** נמוך או בינוני לעבודה שגרתית.
- **כלים כבדים רק כשצריך:** Research, חיפוש ברשת, יצירת קבצים, connectors (חיבורים לשירותים אחרים).
- **לצרף מעט:** רק את הקובץ או העמודים שצריך. טקסט עדיף על צילום מסך, אלא אם המראה חשוב.
- **לתקן, לא לערום:** תשובה שהלכה לכיוון הלא נכון? ערכו את ההודעה הקודמת ושלחו שוב (בלשונית Code: `/rewind`).

## מה הקיט עושה לבד (בלשונית Code)
- נותן ל-Claude את כללי הצוות בכל צ'אט: עונה בעברית, שומר נתוני לקוחות וסיסמאות מחוץ לקוד משותף, מסביר מושגים.
- נותן לצ'אטים שמות ברורים באפליקציה, כדי שתמצאו אותם שוב.
- מציע `/check` לפני ששולחים משהו החוצה.
- כשיש Python במחשב: עוצר צ'אט שהתארך ושומר סיכום, ומעכב את ההודעה הראשונה לצ'אט
  ארוך שעמד זמן רב (שליחה חוזרת עוברת).
- מתריע כשלצ'אט אין תיקיית עבודה, כדי שהסיכום לא יישמר במקום שבו הוא הולך לאיבוד.
- שומר על תשובות קצרות וענייניות, עם שורה תחתונה כשהן מתארכות (אפשר לכבות ב-`/start`).
- מזכיר ל-Claude לבדוק מה כבר קיים לפני שבונים משהו חדש.
- בתיקייה שכבר עובדת עם git: שומר כל קובץ ש-Claude עורך, במחשב שלכם בלבד, כדי שאפשר יהיה לבטל עריכה גרועה.
- מציג שורה מעל תיבת ההקלדה: כמה זמן Claude עוד זוכר את הצ'אט בזול, וכמה הצ'אט מלא.
- שומר פתק קצר עליכם כשמריצים `/start`, ולא נוגע בשום דבר אחר שלכם.
- מנהל Claude של החברה רואה כמה אתם משתמשים, ולא שום דבר אחר.

## מה נשאר אצלכם
לבחור מודל, לפתוח צ'אט חדש בזמן, ולבדוק בעצמכם כל מה שהולך ללקוח.
