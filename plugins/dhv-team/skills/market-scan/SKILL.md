# Who already sells this?

Products are often sold under a category name you would not guess (a "meeting notetaker" is "compliance
recording" to a bank). Comparing the same shortlist deeper never finds that. **Widen, never deepen.**
Reply in the person's language.

## 1. Brief (about 4 lines, shown to the person; carry on unless corrected)

    Need:     the mechanism in plain words, not a product label
    Must:     hard requirements (Hebrew, Microsoft 365, where data is stored, budget if known)
    Searched: categories and products already looked at; the scan goes elsewhere first
    Walls:    every "X can't do Y" found so far

Add the company's approved-tools list, if the person has one, and what the company already owns.

## 2. Scan

If you can start a separate helper, give it the brief and these steps without the chat history (history
favours the path already taken), about 20 web searches, and "breadth over depth: no deep dive on any
one vendor". Otherwise run it yourself, in this order:
1. **Category names.** At least 3 names the need is sold under: the small-business name, the
   enterprise or regulated-industry name (compliance, records management, contact centre...), and the
   platform add-on name.
2. **Already have.** The approved list; built-in features of what is owned (Microsoft 365, Excel,
   Claude); tools colleagues already built.
3. **Platform catalogues.** Certified-partner and marketplace lists of the platform the need sits on.
4. **Walls.** For each wall: search "who sells Y for X".
5. **Local.** Israeli and Hebrew-native vendors; search in Hebrew too.
6. **Analyst and review categories** (Gartner, G2), mainly to find more category names.
7. **Round two.** New searches from the hits' own words: their category labels, "alternatives to <hit>".
8. **"Best X" lists last**; they show who pays for placement.

Per candidate: what it does, category, meets Must (yes / no / unknown), public price if shown, Israeli?,
approved?, link. Claims taken only from the vendor's site are marked "vendor claim".

## 3. Report
1. **Longlist** grouped by category, with a count each (10-30 in total is normal).
2. **Worth a call:** 3-5 names, one line each.
3. **Not looked at:** categories or sources skipped, and why.
4. **Searches run.**
5. **Ask IT / security** which of these are already approved.

## Never
- Answer "check again" with more depth on the same shortlist: new categories first.
- Recommend building before a longlist exists.
- Treat an approval mentioned in passing as confirmed: write "approved per <who>, unverified".
